# Дизайн-документ: Пагінація навчальних днів при кількості більше 6 (Пункт 7)

## 1. Огляд та мета
Відповідно до вимог `MainChange.md` (Пункт 7) та `plan.md` (Пункт 8), якщо кількість навчальних днів для посади перевищує 6 (наприклад, 8, 10 або до 30 днів), список днів у меню повинен розбиватися на сторінки по 6 днів на сторінку.
На першій сторінці відображаються Дні 1–6 з кнопкою переходу на наступну сторінку `➡️`. На другій сторінці — Дні 7–8 (і т.д.) з кнопкою повернення `⬅️`.

---

## 2. Інтерфейс меню навчання стажера (`bot/keyboards.py`, `bot/handlers.py`)

### 2.1. `learning_menu_keyboard`
- Параметри:
  - `day_statuses`: список `(day, DayStatus)`.
  - `syllabus_enabled: bool = True`: чи відображати кнопку «Зміст».
  - `total_days: Optional[int] = None`: загальна кількість днів.
  - `page: int = 0`: поточна сторінка (0-indexed).
- Логіка пагінації:
  - Константа: `PER_PAGE = 6`.
  - Розрахунок сторінок: `pages_total = max(1, (len(day_statuses) + PER_PAGE - 1) // PER_PAGE)`.
  - Вибірка для поточної сторінки: `paginated_days = day_statuses[start:start + PER_PAGE]`.
  - Рядок пагінації (додається лише якщо `pages_total > 1`):
    - `[ ⬅️ ]` (якщо `page > 0`, callback `learning_days_page:{page-1}`)
    - `[ 📄 {page+1}/{pages_total} ]` (callback `ignore`)
    - `[ ➡️ ]` (якщо `page < pages_total - 1`, callback `learning_days_page:{page+1}`)
  - Додаткові кнопки (внизу клавіатури):
    - `[ 📚 Зміст ]` / `[ 🔒 Зміст ]` (якщо `syllabus_enabled`)
    - `[ 🏠 В головне меню ]` (callback `main_menu`)

### 2.2. Обробник у `bot/handlers.py`
- Додається обробник для `learning_days_page:{page}`:
  - Отримує номер сторінки `page`.
  - Викликає `get_days_overview(user_id, role=user_role)`.
  - Оновлює клавіатуру через `message.edit_reply_markup` або `_show_text_menu` без зміни тексту повідомлення.

---

## 3. Адміністративні меню вибору днів (`bot/menus/developer.py`)
- Для вибору днів при редагуванні матеріалів, відео, тестів та фото:
  - Кількість днів отримується динамічно з `get_days_count_for_role(role)` (замість жорсткого `DAYS_TOTAL = 5`).
  - Якщо кількість днів для посади `> 6`, застосовується аналогічна пагінація по 6 днів на сторінку.

---

## 4. План тестування
1. **Тест пагінації при `<= 6` днів:**
   - 5 днів -> 1 сторінка, відсутні стрілки навігації `⬅️`/`➡️`.
2. **Тест пагінації при `> 6` днів (наприклад, 8 днів):**
   - Сторінка 0: Дні 1–6, кнопка `➡️` з callback `learning_days_page:1`.
   - Сторінка 1: Дні 7–8, кнопка `⬅️` з callback `learning_days_page:0`.
3. **Тест переходів:**
   - Перевірка коректного перемикання сторінок без помилок Telegram API.
