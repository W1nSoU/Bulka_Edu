# Дизайн-документ: Перейменування Dev ➔ Адміністратор, реструктуризація панелі та фотошапки

## 1. Мета
Реалізація Пункту 9 з `docs/changes/MainChange.md` (Пункт 10 плану):
1. Перейменування відображення ролі та меню: «Dev» → «Адміністратор», «Dev-панель» → «Панель Адміністратора», «Команда Dev» → «Команда Адміністраторів».
2. Чітка категоризація панелі адміністратора за 4 напрямками:
   - **Навчальні матеріали**: Матеріали, Відео, Тести, Фото, Змінити змісти, Нагадати тему.
   - **Аналітика**: Аналітика, Помилки тестів, Ознайомлення, Історія нагадувань, XLSX звіт.
   - **Команда Bulka**: Користувачі, Команда Керівників, Команда Адміністраторів, Територіали, Наглядачі.
   - **Інше**: Посади, Міста, Токени, Health Status.
3. Додавання фотошапок з папки `img/admin/` для кожного головного розділу та категорії:
   - `admin_cho.jpg` — Головна панель вибору категорії.
   - `admin_study.jpg` — Навчальні матеріали.
   - `admin_analyt.jpg` — Аналітика.
   - `admin_spus.jpg` — Команда Bulka.
   - `admin_tools.jpg` — Інше.
