# Специфікація: Виняток для закріплених за Шилоносовою В.О. у списку користувачів без керівника

## 1. Огляд та проблема
У боті функція `is_user_without_store_manager` визначає, чи є у співробітника (стажера або працівника) повноцінний керівник магазину. За замовчуванням, якщо співробітник закріплений за Територіалом або за його магазином у базі немає закріпленого директора магазину, система вважає співробітника «без керівника магазину» та відображає у розділах:
- «🎓 Стажери без керівника»
- «👷 Працівники без керівника»

Проте для закладів TIKO KAVA (TK-1..8) та DOGGER окремих директорів магазинів не передбачено — ними безпосередньо та повноцінно керує Територіал **Шилоносова Валерія Олексіївна**. Через це всі 12 стажерів цих закладів помилково потрапляють у список «без керівника», створюючи шум та дезінформацію для адміністрації.

**Мета:** Внести правило-виняток у функцію `is_user_without_store_manager`: якщо користувач закріплений за активним керівником/територіалом Шилоносовою Валерією Олексіївною, вважати, що повноцінний керівник у нього є (`return False`).

---

## 2. Зміни в архітектурі та компонентах

### `database/managers.py` -> `is_user_without_store_manager(user: dict) -> bool`
1. Отримуємо `manager_id = user.get("manager_id")`.
2. Якщо `manager_id` заданий:
   - Отримуємо запис керівника: `mgr = await get_manager_by_uid(manager_id)`.
   - Перевіряємо статус активності (`mgr and mgr.get("status") != "fired"`).
   - Якщо це Шилоносова Валерія Олексіївна (перевірка `"шилоносова" in (mgr.get("full_name") or "").lower()`):
     - Повертаємо `False` (користувач має діючого керівника).
3. Якщо це інший керівник/територіал, продовжується дія стандартних правил:
   - `if await is_territorial_user(manager_id): return True`
   - перевірка `get_manager_by_shop(city, shop)`
   - перевірка активності керівника.

---

## 3. Обробка граничних випадків
- **Звільнення/деактивація:** Якщо керівник зі статусом `fired`, виняток не спрацьовує і користувачі повертаються до списку без керівника.
- **Регістр та написання імені:** Пошук за підрядком `"шилоносова"` у нижньому регістрі гарантує стійкість до форматування ПІБ.

---

## 4. Тестування
- Модульний тест:
  - Співробітник з `manager_id` Шилоносової повертає `is_user_without_store_manager == False`.
  - Співробітник з `manager_id` іншого територіала повертає `is_user_without_store_manager == True`.
  - Співробітник без `manager_id` повертає `is_user_without_store_manager == True`.
