# Специфікація: Очищення та видалення опитувань

## 1. Мета та огляд
Надати розробникам та адміністраторам бота зручний та безпечний інструмент для видалення тестових та застарілих опитувань:
1. **Видалення конкретного опитування** з його картки (з підтвердженням дії).
2. **Масове очищення завершених опитувань** із загального списку опитувань (з підтвердженням дії).
3. **Каскадне очищення пов'язаних даних** у базі даних (запитання, реципієнти, відповіді).

---

## 2. База даних (`database/surveys.py`)

Оскільки в SQLite зовнішні ключі з автоматичним каскадом (`ON DELETE CASCADE`) вимагають увімкнення `PRAGMA foreign_keys = ON`, на рівні функцій бази даних реалізується явне та надійне очищення в межах однієї транзакції.

### 2.1. `delete_survey(survey_id: int, db_path: str = DB_PATH) -> bool`
Послідовно видаляє дані за `survey_id`:
1. `DELETE FROM survey_answers WHERE survey_id = ?`
2. `DELETE FROM survey_recipients WHERE survey_id = ?`
3. `DELETE FROM survey_questions WHERE survey_id = ?`
4. `DELETE FROM surveys WHERE id = ?`

Повертає `True` у разі успішного виконання або `False` при помилці.

### 2.2. `get_closed_surveys_count(db_path: str = DB_PATH) -> int`
Рахує кількість опитувань зі статусом `closed`:
```sql
SELECT COUNT(*) FROM surveys WHERE status = 'closed'
```

### 2.3. `delete_closed_surveys(db_path: str = DB_PATH) -> int`
Знаходить ID усіх закритих опитувань:
```sql
SELECT id FROM surveys WHERE status = 'closed'
```
Для знайдених ID виконує каскадне видалення з `survey_answers`, `survey_recipients`, `survey_questions` та `surveys`.
Повертає кількість видалених опитувань (`int`).

## 3. Інтерфейс користувача (`bot/menus/developer.py`)

### 3.1. Видалення конкретного опитування з картки
1. **Кнопка в `_show_survey_card_view`:**
   - До списку кнопок додається:
     `[🗑 Видалити опитування]` (callback: `dev_survey_del_confirm:{survey_id}`).
   - Відображається лише для розробників/адміністраторів (`not is_obs`).

2. **Діалог підтвердження (`dev_survey_del_confirm_handler`):**
   - Текст повідомлення:
     ```
     🗑 <b>Видалення опитування #{survey_id}</b>
     ───────────────────
     Ви дійсно бажаєте безповоротно видалити опитування <b>«{title}»</b>?

     ⚠️ <i>Це призведе до повного видалення всіх запитань, списку отримувачів та надісланих відповідей співробітників. Цю дію неможливо скасувати.</i>
     ```
   - Кнопки:
     - `[🔴 Так, видалити]` (callback: `dev_survey_del_do:{survey_id}`)
     - `[🔙 Скасувати]` (callback: `dev_survey_card:{survey_id}`)

3. **Виконання видалення (`dev_survey_del_do_handler`):**
   - Перевірка прав доступу (`_ensure_developer(callback, allow_observer=False)`).
   - Виклик `delete_survey(survey_id)`.
   - Показ `callback.answer("✅ Опитування успішно видалено!", show_alert=True)`.
   - Повернення користувача до першої сторінки списку опитувань (`dev_surveys_list_handler`).

### 3.2. Масове очищення завершених опитувань
1. **Кнопка у списку опитувань (`dev_surveys_list_handler`):**
   - Викликається `get_closed_surveys_count()`.
   - Якщо `closed_count > 0` і користувач не є спостерігачем (`not is_obs`), додається кнопка:
     `[🧹 Очистити завершені ({closed_count})]` (callback: `dev_surveys_clear_closed_confirm`).

2. **Діалог підтвердження (`dev_surveys_clear_closed_confirm_handler`):**
   - Текст повідомлення:
     ```
     🧹 <b>Очищення завершених опитувань</b>
     ───────────────────
     Знайдено завершених опитувань: <b>{closed_count}</b> шт.

     ⚠️ <i>Ви впевнені, що хочете безповоротно видалити всі завершені опитування та їхні результати з бази даних?</i>
     ```
   - Кнопки:
     - `[🔴 Так, очистити все]` (callback: `dev_surveys_clear_closed_do`)
     - `[🔙 Скасувати]` (callback: `dev_surveys_list:0`)

3. **Виконання очищення (`dev_surveys_clear_closed_do_handler`):**
   - Перевірка прав доступу (`_ensure_developer(callback, allow_observer=False)`).
   - Виклик `delete_closed_surveys()`.
   - Показ `callback.answer(f"✅ Очищено опитувань: {deleted_count} шт.", show_alert=True)`.
   - Оновлення списку опитувань (`dev_surveys_list_handler`).

---

## 4. Безпека та обмеження
- Тільки користувачі з правами розробника (адміністратора) мають право видаляти опитування (`allow_observer=False`).
- Спостерігачі (`observer`) не бачать кнопок видалення, а при спробі виклику через прямий callback отримують відмову в доступі.
- Усі операції з базою даних є атомарними (одна транзакція) з обробкою винятків та логуванням.

---

## 5. План тестування
1. **Тест каскадного видалення окремого опитування:**
   - Створення опитування з запитаннями, реципієнтами та відповідями.
   - Виклик `delete_survey(survey_id)`.
   - Перевірка, що в усіх 4 таблицях не залишилося жодного запису для цього `survey_id`.
2. **Тест підрахунку та масового видалення закритих опитувань:**
   - Створення активного опитування (`status='active'`) та двох закритих (`status='closed'`).
   - Перевірка `get_closed_surveys_count()` == 2.
   - Виклик `delete_closed_surveys()`.
   - Перевірка, що закриті опитування видалено, а активне опитування залишилося недоторканим.
