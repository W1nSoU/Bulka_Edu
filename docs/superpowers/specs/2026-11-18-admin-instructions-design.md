# Дизайн: Розділ «Інструкції» для адміністраторів + інтеграція в пошук ШІ

**Дата:** 2026-11-18
**Статус:** Затверджено користувачем

## 1. Мета
Додати для адміністраторів (розробників та HR без режиму читання) підрозділ **«📋 Інструкції»** у меню **«📚 Навчальні матеріали»**. Адміністратори зможуть створювати, переглядати (з пагінацією), завантажувати/оновлювати `.docx`-файли за корпоративним шаблоном, змінювати назви та видаляти інструкції. Усі непорожні інструкції автоматично додаються до гібридного пошуку ШІ («Нагадати тему») нарівні з навчальними матеріалами.

## 2. Доступ та видимість
- Кнопка **`📋 Інструкції`** (`callback_data="dev_instructions_menu"`) відображається в `_admin_study_keyboard` **лише для адміністраторів** (не показується наглядачам та територіалам, а також відсутня в меню стажерів, працівників та керівників).
- Усі обробники розділу захищені перевіркою адміністративного доступу (`_check_instructions_admin`).
- При цьому текстовий вміст інструкцій індексується з `role="ALL"`, тож ШІ-радник («Нагадати тему») використовує інструкції для відповідей **усім** користувачам на 1-му етапі пошуку, а сам інтерфейс та файли інструкцій бачать лише адміністратори.

## 3. База даних (`database/instructions.py`)
Окрема таблиця `instructions` у `users.db` + локальне сховище `.docx`-файлів у `database/instructions_files/`:
- `id`: `INTEGER PRIMARY KEY AUTOINCREMENT`
- `title`: `TEXT NOT NULL` (назва теми інструкції)
- `content`: `TEXT DEFAULT ''` (витягнутий чистий текст із `.docx` для ШІ)
- `file_path`: `TEXT DEFAULT NULL` (шлях до файлу на диску)
- `telegram_file_id`: `TEXT DEFAULT NULL` (`file_id` у Telegram для швидкої повторної відправки)
- `file_name`: `TEXT DEFAULT NULL` (оригінальна назва файлу)
- `created_by`: `INTEGER DEFAULT 0`
- `created_at`: `TIMESTAMP DEFAULT CURRENT_TIMESTAMP`
- `updated_at`: `TIMESTAMP DEFAULT CURRENT_TIMESTAMP`

## 4. Робота з Word-файлами (`bot/services/instructions_docx.py`)
- **`generate_instruction_template_docx(topic_title)`**: генерує структурований `.docx`-шаблон (`Шаблон_інструкції_BULKA.docx`) із розділами: Назва теми, 1. Загальні положення, 2. Основні правила, 3. Покроковий алгоритм дій, 4. Важливі застереження та типові помилки (таблиця), 5. Часті запитання.
- **`extract_text_from_docx_bytes(file_bytes)`**: витягує текст з усіх параграфів та таблиць `.docx`-файлу для індексації в пошуку ШІ.

## 5. Користувацький шлях (UI / FSM, `bot/menus/instructions.py`)
1. **Список інструкцій (`dev_instructions_menu` / `dev_inst_page:{page}`):**
   - Кнопка `➕ Додати інструкцію` зверху.
   - Інлайн-список інструкцій (по 8 на сторінку, з позначкою `(порожня)`, якщо файл не завантажено).
   - Інлайн-пагінація вперед/назад (`⬅️` / `{page}/{total_pages}` / `➡️`).
   - Кнопка `🔙 Назад` до `📚 Навчальні матеріали`.
2. **Створення інструкції (`➕ Додати інструкцію`):**
   - Крок 1: запит *«Вкажіть назву теми»*.
   - Крок 2: пропозиція завантажити `.docx`-файл з кнопками `📥 Викачати шаблон` (надсилає `Шаблон_інструкції_BULKA.docx` і продовжує чекати файл), `⏭ Залишити пусту` (створює інструкцію без файлу) та `🔙 Назад`.
   - При завантаженні `.docx` зберігається файл, витягується текст, створюється запис в БД, оновлюється індекс ШІ та відкривається картка інструкції.
3. **Картка інструкції (`dev_inst_view:{id}:{page}`):**
   - При натисканні на елемент зі списку бот надсилає назву і файл інструкції (або текстове повідомлення, якщо порожня) та інлайн-кнопки:
     - `🔄 Змінити файл` — надсилає поточний файл інструкції (якщо є) і шаблон `Шаблон_інструкції_BULKA.docx`, очікує **лише** `.docx`-файл, має кнопку `🔙 Назад`.
     - `✏️ Змінити назву` — запитує нову назву теми, оновлює БД та індекс ШІ.
     - `🗑 Видалити` — запитує підтвердження та видаляє інструкцію з БД, диска та індексу ШІ.
     - `🔙 Назад` — повертає до списку на відповідну сторінку.

## 6. Інтеграція з пошуком ШІ («Нагадати тему»)
- `database/knowledge_chunks.py`: `get_materials_fingerprint` та `get_materials_rows` включають записи з таблиці `instructions` (`id = -inst_id`, `role = 'ALL'`, `day = 0`, `content_type = 'instruction'`, `title = 'Інструкція: ...'`).
- `bot/services/knowledge_chunker.py`: чанкує текст інструкції з префіксом назви теми для кращого лексичного та векторного пошуку.
- `bot/services/semantic_search.py`: `format_sources_label` форматує цитування як `Інструкція: {Назва теми}`.
- При будь-якому додаванні, оновленні файлу, перейменуванні чи видаленні інструкції викликається фонова синхронізація індексу `build_and_reset_embeddings()`.
