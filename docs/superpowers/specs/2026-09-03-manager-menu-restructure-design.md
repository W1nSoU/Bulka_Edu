# Дизайн меню для Керівників (Переформування Панелі Керівника)

**Дата:** 2026-09-03  
**Статус:** Схвалено користувачем  
**Тема:** Переформування меню керівника відповідно до нової модульної ієрархії, додавання ізольованого пошуку та розділу навчання з read-only матеріалами.

---

## 1. Мета та огляд

Поточне меню керівника («Панель Керівника») містить плоский набір кнопок, змішуючи стажерів, фільтри, додавання/видалення та навчальні матеріали в один екран.
Мета цього оновлення:
1. Створити чітку дворівневу модульну структуру з двома основними напрямками: **«👥 Мої працівники»** та **«📚 Навчання»**.
2. Впровадити розділ **«👥 Усі працівники»** з текстовим загальним списком і окремими інлайн-списками карток для стажерів та працівників.
3. Впровадити ізольований **«🔍 Пошук працівника»** (за ID або ПІБ), який шукає **виключно** серед людей, закріплених за магазинами цього керівника.
4. Організувати **«🔎 Фільтри»** (за посадою, активні стажери, завершили навчання, активні працівники з часом останньої активності).
5. Створити розділ **«📚 Навчання»**:
   - «🎓 Навчання керівника»: доступний курс для посади «Керівник» (дні, теми, фото, відео, тести).
   - «📖 Матеріали»: каталог навчальних матеріалів для всіх посад крім «Керівник» у режимі **тільки читання**, плюс «🧠 Нагадати тему».

---

## 2. Архітектура та структура меню

```
[ 👔 Панель Керівника ]
├── [ 👥 Мої працівники ]
│   ├── [ 👥 Усі працівники ]
│   │   ├── [ 📋 Список усіх ] (текстовий звіт про всіх закріплених за магазином)
│   │   ├── [ 🎓 Стажери ] (інлайн-список карток стажерів)
│   │   └── [ 💼 Працівники ] (інлайн-список карток випускників/працівників)
│   ├── [ 🔍 Пошук працівника ] (пошук за ID/ПІБ виключно у своїй команді)
│   ├── [ 🔎 Фільтри ]
│   │   ├── [ 💼 За посадою ]
│   │   ├── [ 🚀 Активні стажери ]
│   │   ├── [ 🎉 Завершили навчання ]
│   │   └── [ ⏱ Активні працівники ] (текстовий список з часом останньої взаємодії)
│   └── [ ➕ Додати стажера ]
└── [ 📚 Навчання ]
    ├── [ 🎓 Навчання керівника ] (курс для посади «Керівник»)
    └── [ 📖 Матеріали ] (read-only перегляд усіх посад крім «Керівник» + «Нагадати тему»)
```

## 3. Деталізація екранів та обробників

### 3.1. Головний екран Панелі Керівника (`manager_menu`)
- **Текст:**
  ```html
  👔 <b>Панель Керівника</b>

  Оберіть розділ для роботи:
  ```
- **Клавіатура:**
  - `[ 👥 Мої працівники ]` ➔ `callback_data="mgr_my_team"`
  - `[ 📚 Навчання ]` ➔ `callback_data="mgr_study_root"`
  - `[ 🏠 Головне меню ]` ➔ `callback_data="main_menu"`

### 3.2. Розділ «👥 Мої працівники» (`mgr_my_team`)
- **Текст:**
  ```html
  👥 <b>Мої працівники</b>
  🏪 Закріплені магазини: <b>{shops_formatted}</b>
  🏙 Місто: <b>{city}</b>

  Оберіть дію:
  ```
- **Клавіатура:**
  - Рядок 1: `[ 👥 Усі працівники ]` ➔ `callback_data="mgr_all_workers_menu"`
  - Рядок 2: `[ 🔍 Пошук працівника ]` ➔ `callback_data="mgr_search_worker"`
  - Рядок 3: `[ 🔎 Фільтри ]` ➔ `callback_data="mgr_filters_menu"`
  - Рядок 4: `[ ➕ Додати стажера ]` ➔ `callback_data="mgr_add"`
  - Рядок 5: `[ ⬅️ Назад ]` ➔ `callback_data="manager_menu"`

### 3.3. Підрозділ «👥 Усі працівники» (`mgr_all_workers_menu`)
- **Визначення команди керівника:**
  Користувачі вважаються закріпленими за керівником, якщо:
  `user.manager_id == manager.uid` АБО `(user.city == manager.city AND user.shop IN manager.shops)`.
- **Клавіатура вибору:**
  - `[ 📋 Список усіх ]` ➔ `callback_data="mgr_list_all_text"`
  - `[ 🎓 Стажери ]` ➔ `callback_data="mgr_interns_list:0"`
  - `[ 💼 Працівники ]` ➔ `callback_data="mgr_workers_list:0"`
  - `[ ⬅️ Назад ]` ➔ `callback_data="mgr_my_team"`

#### Дії у підрозділі:
1. **«📋 Список усіх» (`mgr_list_all_text`):**
   Формує та надсилає структуроване повідомлення:
   ```html
   📋 <b>Список команди ({total} осіб):</b>

   <b>🎓 Стажери:</b>
   1. Шевченко Тарас — Касир (День 2)
   2. Франко Іван — Бариста (День 1)

   <b>💼 Працівники:</b>
   1. Леся Українка — Пекар (Працівник)
   ```
   З кнопкою `[ ⬅️ Назад ]` ➔ `mgr_all_workers_menu`.

2. **«🎓 Стажери» (`mgr_interns_list`):**
   Вибірка: користувачі магазину, де `is_worker == 0` (або `status != 'Працівник'`).
   Інлайн-список із пагінацією (по 10 на сторінку), кожна кнопка веде на картку стажера `mgr_view_intern_{uid}`.

3. **«💼 Працівники» (`mgr_workers_list`):**
   Вибірка: користувачі магазину, де `is_worker == 1` (або `status == 'Працівник'`).
   Інлайн-список із пагінацією, кожна кнопка веде на картку працівника `mgr_view_intern_{uid}`.

### 3.4. Ізольований пошук («🔍 Пошук працівника»)
- **Стан:** `ManagerStates.waiting_search_worker`.
- **Підказка:** *"🔍 <b>Пошук працівника або стажера</b>\n\nВведіть Telegram ID або частину ПІБ:"* з кнопкою `[ ❌ Скасувати ]` ➔ `mgr_my_team`.
- **Логіка пошуку:**
  1. Отримується повний перелік користувачів магазинів даного керівника (`my_team_users`).
  2. Якщо введено ціле число ➔ шукаємо користувача з таким `user_id` **тільки** серед `my_team_users`. Якщо користувач з таким ID є в системі, але належить іншому магазину/керівнику — повертається повідомлення:
     `❌ Користувача з ID {query} не знайдено серед ваших працівників та стажерів.`
  3. Якщо введено текст ➔ шукаємо збіг у `full_name` або `username` (case-insensitive) **тільки** серед `my_team_users`.
  4. Якщо знайдено 1 людину ➔ відкриваємо її картку (`mgr_view_intern_{uid}`).
  5. Якщо знайдено кілька ➔ виводимо список кнопок для вибору.
  6. Якщо не знайдено ➔ виводимо повідомлення про відсутність результатів і пропонуємо ввести інший запит або повернутися назад.

---

### 3.5. Підрозділ «🔎 Фільтри» (`mgr_filters_menu`)
- **Клавіатура:**
  - `[ 💼 За посадою ]` ➔ `callback_data="mgr_filter_by_role"`
    *(список доступних посад серед людей магазину ➔ клік на посаду ➔ інлайн-список людей цієї посади)*
  - `[ 🚀 Активні стажери ]` ➔ `callback_data="mgr_filter_active_interns:0"`
    *(стажери в процесі навчання: `current_block <= DAYS_TOTAL` та активні протягом 3 днів)*
  - `[ 🎉 Завершили навчання ]` ➔ `callback_data="mgr_filter_graduated:0"`
    *(стажери, які завершили всі дні програми або переведені у статус працівника)*
  - `[ ⏱ Активні працівники ]` ➔ `callback_data="mgr_filter_recent_activity"`
    *(текстовий список усіх працівників та стажерів магазину із сортуванням за часом останньої активності у форматі: `ПІБ — 15 хв. тому / 2 год. тому / 3 дн. тому`)*
  - `[ ⬅️ Назад ]` ➔ `callback_data="mgr_my_team"`

---

### 3.6. Розділ «📚 Навчання» (`mgr_study_root`)
- **Текст:**
  ```html
  📚 <b>Навчання та матеріали</b>

  Оберіть необхідний напрямок:
  ```
- **Клавіатура:**
  - `[ 🎓 Навчання керівника ]` ➔ `callback_data="mgr_training_course"`
  - `[ 📖 Матеріали ]` ➔ `callback_data="mgr_materials_catalog"`
  - `[ ⬅️ Назад ]` ➔ `callback_data="manager_menu"`

#### 1. «🎓 Навчання керівника» (`mgr_training_course`):
- Перегляд навчального курсу, створеного спеціально для посади **«Керівник»**.
- Відображаються дні навчання посади (День 1, День 2 тощо), теми, фото, відеоматеріали, теоретичні тексти та тести для посади керівника.

#### 2. «📖 Матеріали» (`mgr_materials_catalog`):
- Каталог навчальних матеріалів для стажерів/працівників.
- Відображає список усіх посад мережі (Бариста, Касир, Пекар тощо), **за винятком посади «Керівник»**.
- Режим **строго тільки для читання**:
  - Керівник може відкрити будь-яку посаду, обрати день і прочитати зміст/матеріали, щоб перевірити знання підлеглого на зміні.
  - Жодних кнопок додавання, зміни чи видалення матеріалів немає.
- Включає кнопку `[ 🧠 Нагадати тему ]` ➔ виклик швидкого пошуку тем за посадами стажерів для допомоги на робочому місці.

## 4. Безпека та перевірка прав

1. **`_ensure_manager(callback)`:**
   - Перевіряє `is_manager_user(user_id) or is_hr_user(user_id) or is_developer_user(user_id)`.
   - Забороняє доступ для сторонніх ролей (Наглядач, Територіал, Стажер).
2. **Ізоляція даних:**
   - Будь-який запит до списків або пошуку у `mgr_my_team` фільтрується за прив'язкою до магазинів конкретного керівника:
     `WHERE manager_id = ? OR (city = ? AND shop IN (...))`
   - Керівник технічно не може отримати картку чи дані стажера з чужого магазину через цей інтерфейс.
