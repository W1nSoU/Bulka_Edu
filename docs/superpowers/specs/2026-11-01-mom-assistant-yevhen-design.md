- **Власник конфігурації:** Данік (технічний запуск)
- **Кінцевий користувач:** Ірина - HRD (Head of HR / Директор з персоналу) у мережі «Булка маркет»
- **Цільова директорія проекту:** `/Users/daniildusinskij/All/Dev/Mom_Assistant`

## 1. Мета та Філософія Проекту

Створити персонального Telegram-асистента «Євген» для Ірини. Бот позиціонується як особистий діловий та життєвий помічник, який працює безпосередньо для неї.

### Ключові принципи:
1. **Абсолютне табу на згадки про розробників та Даніка:** У промптах, конфігураціях, системних інструкціях та повідомленнях бота категорично заборонено згадувати ім'я Даніка чи натякати на те, хто саме налаштував бота. Для Ірини Євген - це її власний приватний помічник.
2. **Ніяких технічних скілів та жаргону:** Повна відсутність програмування, баз даних, CTF, фінансових біржових зведень чи згадок про ШІ/сервери.
3. **Простота інтерфейсу:** Працює виключно в особистих повідомленнях Telegram (Direct Messages). Жодних супергруп, форумів, топіків чи складних команд.
4. **Підтримка голосових повідомлень:** Ірина може вільно надиктовувати запитання голосом на ходу, асистент розпізнає аудіо й відповідає текстом.
5. **Контекст HRD:** Євген розуміє специфіку управління персоналом у ритейлі (Булка маркет), допомагає формулювати оголошення, скрипти співбесід, вирішувати трудові питання та складати ділові листи.
6. **Турботливий та шанобливий тон:** Ввічливий, шанобливий, спокійний і надійний стиль спілкування («Євген», звертання на «Ви» з повагою).

## 2. Архітектура Системи

Система є автономним мікро-мостом (Micro-Bridge), що дублює перевірену технологію шлюзу Antigravity без громіздких залежностей:

```text
[Telegram App (Мама)]
        │  (Текст або Голосове OGG)
        ▼
[bot.py (Long-Polling)] ──(Фільтр ID: 1001226587, 738460434)
        │
        ├─► [voice_handler.py] (якщо голос: ffmpeg -> WAV -> Whisper/STT)
        │
        ▼
[antigravity_bridge.py] ──(Auto-heal runtime_env, порт + CSRF)
        │
        ▼
[Antigravity Local Engine / agentapi]
        │
        ▼
[tg_reply.py] ──(Відправка відповіді в особисті повідомлення)
        │
        ▼
[Telegram App (Мама)]
```

## 4. Специфікація Компонентів

### 4.1. Telegram Демон (`bot.py`)
- Використовує надійний HTTP Long-polling (через `requests` / чистий Telegram Bot API без важких фреймворків).
- Перевіряє `chat.type == "private"`.
- Перевіряє `from_user.id` за списком дозволених `ALLOWED_USERS`:
  - `1001226587` (Ірина Душинська)
  - `738460434` (Данік)
- Відхиляє сторонніх користувачів безпечним чемним повідомленням.
- Надсилає дію `typing` («друкує...»), поки формується відповідь.

### 4.2. Обробник Голосу (`voice_handler.py`)
- Завантажує надісланий `.ogg` (Opus) файл через Telegram `getFile` API.
- Конвертує у формат 16kHz Mono WAV через локальний бінарник `/opt/homebrew/bin/ffmpeg` або системний `ffmpeg`.
- Використовує локальну транскрибацію або передає аудіо/текст до Antigravity для отримання змісту.
- Формує запит із поміткою: `[Голосове повідомлення від Ірини]: "<розпізнаний текст>"`.

### 4.3. Міст Antigravity (`antigravity_bridge.py`)
- Функція `auto_heal_runtime_env()`:
  - Сканує порти локального сервера Antigravity або читає активний `runtime_env.json`.
  - Валідує валідність з'єднання за допомогою `get-conversation-metadata`.
- Викликає бінарник `agentapi send-message`:
  - Передає запит із системним обрамленням персони Євгена (без згадки технічних розробників чи сторонніх імен).
  - Повертає згенеровану відповідь або ініціює пряму відправку через `tg_reply.py`.

### 4.4. Персона Євгена (`config.json`)
```json
{
  "assistant_name": "Приватний асистент Євген",
  "system_prompt": "Ти - Євген, особистий приватний помічник Ірини. Вона працює HRD (директором з персоналу) у мережі супермаркетів «Булка маркет». Спілкуйся виключно чистою, теплою, шанобливою українською мовою. Твій тон - інтелігентний, спокійний, надійний і турботливий. Звертайся шанобливо (на «Ви»). Якщо питання стосується HR, найму, адаптації, роботи з командами чи вирішення конфліктів на роботі - давай структуровані, практичні та зрілі управлінські поради. Якщо питання побутове, кулінарне, організаційне чи життєве - допомагай просто, лаконічно, щиро та тепло. СУВОРЕ ПРАВИЛО: ніколи не вживай технічного жаргону, програмування чи системних термінів. Ніколи не згадуй сторонніх імен чи будь-яких налаштувань. Для неї ти живий, розумний помічник Євген.",
  "allowed_users": [1001226587, 738460434]
}
```

### 4.5. Відправка Повідомлень (`tg_reply.py`)
- Відправляє повідомлення мамі з підтримкою розбиття на частини (chunks <= 3900 символів), щоб уникнути обмежень Telegram.
- Безпечний парсинг Markdown (якщо парсинг падає - автоматично повторює відправку чистим текстом).

### 4.6. Скрипти Керування (`start.sh`, `stop.sh`)
- `start.sh`:
  - Перевіряє наявність Python 3 та віртуального оточення.
  - Запускає `caffeinate -s -i python3 bot.py > logs/assistant.log 2>&1 &`.
  - Зберігає PID у `bot.pid`.
- `stop.sh`:
  - Читає `bot.pid` і коректно зупиняє процес (`kill -15`, потім `kill -9` за потреби).

## 5. Безпека та Надійність

1. **Захист від несанкціонованого доступу:** Бот суворо закритий на 2 ID. Чужі користувачі не мають доступу до ресурсів асистента.
2. **Захист від засинання Mac:** `caffeinate` у `start.sh` гарантує безперервну роботу демона.
3. **Автономне відновлення з'єднання:** Якщо локальний порт Antigravity змінився після перезавантаження сесії, `antigravity_bridge.py` автоматично сканує активні сокети й оновлює конфігурацію.
4. **Ізоляція даних:** Усі логи та тимчасові файли зберігаються локально в `Mom_Assistant/logs/` і не змішуються з іншими проектами.

## 6. План Тестування та Верифікації

1. **Тест конфігурації:** Перевірка токена бота через метод `getMe` Telegram Bot API.
2. **Тест фільтрації:** Спроба надіслати повідомлення з дозволеного ID (Данік `738460434`) та перевірка відхилення сторонніх.
3. **Тест текстового діалогу:** Запит на HR-тему (наприклад: *«Євгене, підкажи план адаптації нового керуючого магазином»*) та перевірка збереження тону, стилю й відсутності технічного шуму.
4. **Тест голосового повідомлення:** Надсилання короткого аудіо, перевірка конвертації через `ffmpeg` та отримання адекватної відповіді.
5. **Тест стабільності процесу:** Перевірка старту через `start.sh` та зупинки через `stop.sh`.
