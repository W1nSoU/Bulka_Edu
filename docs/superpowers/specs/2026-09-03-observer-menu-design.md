# Дизайн-специфікація: Меню Наглядача та Профіль Наглядача (Bulka Edu)

## Мета та призначення
Реалізувати повноцінне меню для ролі **Наглядач** (`process = 'Наглядач'`), що повторює структуру та візуальний стиль меню адміністратора (4 категорії), але суворо обмежує права до режиму **«Тільки читання» (Read-Only)**.
Також адаптувати картку профілю Наглядача («Профіль наглядача-Булочки») із загальною статистикою системи та відповідним привітанням.

---

## 1. Головне меню та навігація (`developer_menu`)

1. **Точка входу:**
   - Команда `/start` показує вітальний екран Наглядача з банером `img/admin/admin_menu.jpg` та клавіатурою:
     - `[ 👤 Профіль ]` (`profile`)
     - `[ 🚀 Почати роботу ]` (`developer_menu`)
   - При натисканні `[ 🚀 Почати роботу ]` відкривається банер `img/admin/admin_cho.jpg` із заголовком:
     > 👁 **Панель управління Bulka (Наглядач)**
     > Оберіть потрібний розділ для моніторингу:
2. **Клавіатура вибору категорії (`_admin_cho_keyboard`):**
   - Для `is_observer = True` відображаються всі 4 категорії:
     1. `[ 📚 Навчальні матеріали ]` (`dev_main_study`)
     2. `[ 📊 Аналітика ]` (`dev_main_analyt`)
     3. `[ 👥 Команда Bulka ]` (`dev_main_team`)
     4. `[ 🛠 Інше ]` (`dev_main_other`)
     5. `[ 🏠 В головне меню ]` (`main_menu`)

---

## 2. Підрозділи та обмеження режиму «Тільки читання»

### 2.1. «📚 Навчальні матеріали» (`_admin_study_keyboard`)
- **Кнопки розділу для Наглядача:**
  - `[ 📝 Матеріали ]` (`dev_materials_menu`)
  - `[ 🎥 Відео ]` (`dev_videos_menu`)
  - `[ 📝 Тести ]` (`dev_tests_menu`)
  - `[ 🖼 Фото ]` (`dev_photos_menu`)
  - `[ 🧠 Нагадати тему ]` (`remind_topic_global`)
  - `[ 🔙 Назад ]` (`developer_menu`)
  - ❌ Кнопку `[ 📚 Змінити змісти ]` (`dev_syllabus_menu`) приховано.
- **Підменю матеріалів, відео, тестів, фото:**
  - Наглядач може відкривати списки, обирати посаду/день та читати/переглядати вміст матеріалів, відео, фото та запитання/відповіді тестів.
  - Кнопки додавання (`➕ Додати`), редагування (`✏️ Редагувати`) та видалення (`❌ Видалити`) приховано з клавіатур для `is_observer`.
  - **Бекенд-захист:** Усі колбек-хендлери створення/редагування/видалення матеріалів та тестів перевіряють `is_observer_user(user_id)` і за наявності ролі наглядача відповідають:
    `⛔️ У вас режим перегляду (тільки читання).`

### 2.2. «📊 Аналітика» (`_admin_analyt_keyboard`)
- Для Наглядача доступні:
  - `[ 📊 Аналітика ]` (`dev_analytics_menu`)
  - `[ 📊 Помилки тестів ]` (`show_test_errors`)
  - `[ 📋 Ознайомлення ]` (`dev_an_ack_menu`)
  - `[ 📜 Історія нагадувань ]` (`dev_reminder_history`)
  - `[ 🔙 Назад ]` (`developer_menu`)
- Кнопка `[ 📊 XLSX звіт ]` (`dev_xlsx_menu`) прихована для `is_observer`.

### 2.3. «👥 Команда Bulka» (`_admin_team_keyboard`)
- **Кнопки розділу для Наглядача:**
  - `[ 👥 Користувачі ]` (`dev_users_menu`)
  - `[ 👔 Команда Керівників ]` (`dev_manage_managers`)
  - `[ 🔙 Назад ]` (`developer_menu`)
  - (Списки адміністраторів, територіалів та наглядачів залишаються лише для `is_admin`).
- **Співробітники (`dev_users_menu`):**
  - У меню персоналу (`_users_staff_keyboard`) приховано кнопку `[ ➕ Додати ]`.
  - Пошук за ID, фільтрація за містом, посадою та перегляд списків працюють у звичайному режимі.
  - **Картка працівника (`_show_user_profile_card`):**
    - Текст картки відображає всі деталі користувача та статус проходження днів (🔓/🔒).
    - Для `is_observer` приховано кнопки `[ 📅 Навчальні дні ]`, `[ ✍️ Змінити ]` та `[ ❌ Видалити ]`.
    - Залишається **лише кнопка `[ ⬅️ Назад ]`** (через колбек `dev_u_cback:{ret_code}` з автоматичним видаленням фото картки).
- **Керівники (`dev_manage_managers`):**
  - Кнопку `[ ➕ Додати керівника ]` приховано.
  - У картці керівника (`_build_manager_card`) кнопки `[ ✏️ Змінити ]` та `[ 🔄 Перепривʼязати ]` приховано. Залишається лише `[ ⬅️ Назад до списку ]`.

### 2.4. «🛠 Інше» (`_admin_other_keyboard`)
- **Кнопки розділу для Наглядача:**
  - `[ 👔 Посади ]` (`dev_positions_menu`)
  - `[ 🏙 Міста ]` (`dev_cities_menu`)
  - `[ 💚 Health Status ]` (`dev_health_status`)
  - `[ 🔙 Назад ]` (`developer_menu`)
  - ❌ Кнопки `[ 🎟 Токени ]` та `[ ⚙️ Сервісні функції ]` повністю приховано для `is_observer`.
- **Довідники Посад та Міст:**
  - При переході в «Посади» чи «Міста» наглядач бачить списки, але кнопки додавання нових позицій чи видалення приховано.

## 3. Профіль Наглядача («Профіль наглядача-Булочки»)

При натисканні `[ 👤 Профіль ]` (`profile`):
1. **Маршрутизація в `bot/handlers.py`:**
   - Якщо користувач є наглядачем (`await is_observer_user(user_id)`), викликається `observer_profile_handler`.
2. **Формат тексту картки:**
   ```text
   🍞 <b>Профіль наглядача-Булочки</b> 🍞

   👤 <b>{full_name}</b> ({username})
   🔹 Посада: <b>Наглядач</b>

   📈 <b>Загальна статистика системи:</b>
   — Всього користувачів: <b>{total_users}</b>
   — Стажерів у процесі навчання: <b>{interns_in_progress}</b>
   — Закінчили навчання (працівники): <b>{graduated_workers}</b>
   — Активних керівників: <b>{total_managers}</b>

   👁✨ <i>Ви — пильне та турботливе око нашої мережі Bulka! Дякуємо за вашу увагу до кожної деталі. Разом до нових звершень!</i> 🍞
   ```
3. **Клавіатура картки:**
   - `[ 🏠 В головне меню ]` (`main_menu`)
4. **Фото:**
   - Аватарка наглядача через `get_user_avatar_input(callback.bot, user_id)` з фолбеком на системне фото.

## 4. План тестування та верифікації
1. **Тест ролі Наглядача в головному меню:**
   - Перевірка, що `developer_menu` для наглядача відображає 4 категорії.
   - Перевірка відсутності кнопок `Токени`, `Сервісні функції`, `Змінити змісти`.
2. **Тест карток користувача та керівника:**
   - Перевірка, що під карткою користувача для наглядача є лише кнопка «Назад» (без днів, редагування, видалення).
   - Перевірка відсутності кнопки «Додати працівника» у меню персоналу.
3. **Тест карток матеріалів та тестів:**
   - Перевірка, що списки матеріалів відкриваються на читання, але кнопки мутацій (add/edit/delete) відсутні.
4. **Тест профілю Наглядача:**
   - Перевірка, що `profile` для наглядача виводить заголовок «Профіль наглядача-Булочки» та загальну статистику системи.
5. **Регресійний набір тестів:**
   - Запуск усіх наявних тестів проекту (`scratch/test_*.py`).
