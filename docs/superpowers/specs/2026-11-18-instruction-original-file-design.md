# Дизайн: Підтримка оригіналу документа в розділі «Інструкції»

**Дата:** 2026-11-18
**Статус:** Затверджено користувачем

## 1. Мета
Розширити функціонал **«📋 Інструкції»** можливістю прикріплювати до кожної інструкції повний **оригінал документа** (будь-який файл: `.pdf`, `.docx`, `.doc`, `.xlsx` тощо до 20 МБ) на додачу до `.docx`-інструкції для індексації в ШІ.

Пошук ШІ («Нагадати тему») продовжує виконуватися виключно по тексту інструкції для ШІ (і навчальних матеріалах), а у відповідь користувачеві бот надсилає сформовану текстову відповідь **та прикріплює файл оригіналу** тих інструкцій, які ШІ реально використав у відповіді.

## 2. База даних (`database/instructions.py`)
- Таблиця `instructions` доповнюється колонками (з безпечною авто-міграцією через `PRAGMA table_info` + `ALTER TABLE ADD COLUMN` у `init_instructions_db()`):
  - `original_file_path TEXT DEFAULT NULL` - шлях до оригіналу на диску (`database/instructions_files/`).
  - `original_telegram_file_id TEXT DEFAULT NULL` - `file_id` у Telegram для швидкої відправки.
  - `original_file_name TEXT DEFAULT NULL` - оригінальна назва файлу.
- Нові та оновлені функції:
  - `create_instruction(...)` - приймає необов'язкові параметри оригіналу (`original_file_path`, `original_telegram_file_id`, `original_file_name`).
  - `update_instruction_original_file(inst_id, original_file_path, original_telegram_file_id, original_file_name)` - оновлює файл оригіналу та видаляє попередній файл оригіналу з диска.
  - `delete_instruction(inst_id)` - видаляє з диска і файл інструкції для ШІ, і файл оригіналу.
  - `get_instructions_with_original_by_ids(inst_ids)` - повертає інструкції у порядку `inst_ids`, у яких є прикріплений оригінал.

## 3. Користувацький шлях адміністратора (`bot/menus/instructions.py`)
1. **Створення інструкції (3 кроки):**
   - **Крок 1/3 (`waiting_new_title`):** запит назви теми (`Вкажіть назву теми:`).
   - **Крок 2/3 (`waiting_new_file`):** завантаження `.docx`-інструкції для ШІ або кнопки `📥 Викачати шаблон`, `⏭ Залишити пусту`, `🔙 Назад`. Після завантаження або пропуску переход до Кроку 3/3 (дані Кроку 2 зберігаються в FSM-стані).
   - **Крок 3/3 (`waiting_new_original_file`):** запит повного оригіналу інструкції (будь-який документ до 20 МБ) з кнопками `⏭ Залишити без оригіналу` та `🔙 Назад` (повертає на Крок 2/3). Після завантаження або пропуску інструкція створюється в БД, запускається фонова переіндексація ШІ (якщо є текст інструкції) та відкривається картка.
2. **Картка інструкції (`dev_inst_view:{id}:{page}`):**
   - Якщо наявні обидва файли: бот надсилає послідовно 2 документи - спочатку файл інструкції для ШІ (`📄 Файл інструкції (для ШІ)`), потім файл оригіналу з повним підписом картки (статус обох файлів) та клавіатурою керування під ним.
   - Якщо є лише один із файлів: надсилає наявний файл із підписом картки та клавіатурою.
   - Якщо обидва файли відсутні: надсилає текстову картку з клавіатурою.
3. **Заміна файлів (`🔄 Замінити файл` -> `dev_inst_replace_menu:{id}:{page}`):**
   - Відкриває підменю вибору:
     - `📄 Замінити інструкцію` (`dev_inst_edit_file:{id}:{page}`) - надсилає поточну інструкцію для ШІ (якщо є) та шаблон `.docx`, очікує новий `.docx` і переіндексовує ШІ.
     - `📎 Замінити оригінал інструкції` (`dev_inst_edit_orig:{id}:{page}`) - надсилає поточний файл оригіналу (якщо є), очікує новий документ будь-якого формату і оновлює оригінал в БД.
     - `🔙 Назад` (`dev_inst_view:{id}:{page}`).

## 4. Надсилання оригіналу при пошуку ШІ (`bot/services/openai_ai.py`, `bot/handlers.py`)
- Кожен чанк інструкції вже містить у `sources` запис із `material_id = -inst_id`, `day = 0`, `title = "Інструкція: {Назва теми}"`.
- `answer_remind_topic` через `_extract_used_instruction_ids(results, answer_text)` визначає список `used_instruction_ids`:
  1. Усі інструкції з `results`, які ШІ явно процитував або назвав у тексті відповіді (`[Інструкція: ...]` або назва теми).
  2. Якщо явної цитати у відповіді немає, але топ-1 найрелевантніший чанк (`results[0]`) належить інструкції - повертає цю інструкцію.
- `process_keyword_search` у `bot/handlers.py`:
  - Отримує `used_instruction_ids` із результату `answer_remind_topic`.
  - Викликає `get_instructions_with_original_by_ids(used_instruction_ids)`.
  - Якщо є оригінали: спочатку надсилає текстову відповідь ШІ без нижньої клавіатури, а далі почергово надсилає файл(и) оригіналу (`📎 Оригінал інструкції: {title}`) з прикріпленою клавіатурою (`🔁 Нове питання`, `🏠 В головне меню`) до останнього повідомлення.
