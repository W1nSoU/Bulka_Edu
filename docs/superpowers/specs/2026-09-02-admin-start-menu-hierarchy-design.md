# Дизайн-специфікація: Оновлення структури меню та фотошапок адміністраторів

## 1. Мета
Оновити ієрархію меню та фотошапки для адміністраторів (а також ролей Наглядач і Територіал):
1. При команді `/start` (або виході «🏠 В головне меню») показувати стартовий екран з фото `img/admin/admin_menu.jpg`, що містить кнопки `[ 👤 Профіль ]` та `[ 🚀 Почати роботу ]`.
2. Натискання `[ 🚀 Почати роботу ]` відкриває робочу панель з фото `img/admin/admin_cho.jpg` та 4 категоріями керування.
3. Кожна категорія відкривається зі своїм закріпленим фото:
   - **Навчальні матеріали** ➔ `img/admin/admin_study.jpg`
   - **Аналітика** ➔ `img/admin/admin_analyt.jpg`
   - **Команда Bulka** ➔ `img/admin/admin_spus.jpg`
   - **Інше** ➔ `img/admin/admin_tools.jpg`
4. Кнопка `[ 🏠 В головне меню ]` у `admin_cho.jpg` або в профілі повертає на стартовий екран з `admin_menu.jpg`.

## 3. Зміни в коді

### 3.1. `bot/keyboards.py`
- Функція `main_menu_keyboard`:
  - Для `is_developer=True`, `is_observer=True`, `is_territorial=True`:
    - Повертає 2 кнопки:
      - `[ 👤 Профіль ]` (`callback_data="profile"`)
      - `[ 🚀 Почати роботу ]` (`callback_data="developer_menu"`)

### 3.2. `bot/handlers.py`
- `show_developer_main_menu` та `show_observer_main_menu`:
  - Використовують зображення `img/admin/admin_menu.jpg`.
  - Заголовок: *«🛠 <b>Панель управління Булка</b>\n\nВітаємо! Оберіть дію:»* (для Наглядача — *«👁 <b>Панель управління Булка (Наглядач)</b>»*).
- `_show_photo_menu`:
  - Гарантує плавний перехід між фотоповідомленнями або видалення старого тексту та надсилання нового фото `admin_menu.jpg`.

### 3.3. `bot/menus/developer.py`
- `developer_menu_callback`:
  - Відображає `img/admin/admin_cho.jpg` з кнопками 4-х категорій та кнопкою `[ 🏠 В головне меню ]` (`callback_data="main_menu"`).
- `dev_main_study_handler`, `dev_main_analyt_handler`, `dev_main_team_handler`, `dev_main_other_handler`:
  - Відкривають відповідні зображення `admin_study.jpg`, `admin_analyt.jpg`, `admin_spus.jpg`, `admin_tools.jpg`.
- Кнопки `[ 🔙 Назад ]` у категоріях:
  - Повертають до `developer_menu` (`admin_cho.jpg`).
