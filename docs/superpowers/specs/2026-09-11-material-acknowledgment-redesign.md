# Специфікація: Оновлення логіки та інтерфейсу меню ознайомлень (Завдання 69–70)

## 1. Мета та огляд
Відповідно до пунктів 69, 70, 72 у `docs/changes/MainChange.md`:
1. При переході на меню «Ознайомлення» одразу відкривати список з датами оновлень матеріалів (без попереднього вибору категорії персоналу).
2. У картці обраного оновлення відображати:
   - Загальну статистику події (всього отримувачів, скільки ознайомились, скільки ні).
   - Кнопку «Зміст змін» (перегляд опису та сторінок оновленого матеріалу).
   - Кнопку «Вивантажити результати (XLSX)» для генерації звіту.
   - Інлайн-кнопки магазинів з індикацією прогресу ознайомлення (`🏪 b-12 (✅ 3/4)`).
3. При натисканні на магазин показувати детальне структурування:
   - 👔 Керівник (виділено окремо) із позначкою ✅ / ❌ та датою/часом ознайомлення.
   - 👷 Працівники із позначками ✅ / ❌ та датами/часом.
   - 🎓 Стажери із позначками ✅ / ❌ та датами/часом.
4. Кнопки повернення скрізь стандартизовано з лаконічним текстом `⬅️ Назад`.
5. Режим перегляду працює в реальному часі одразу після розсилки (без блокування на 75 годин).
6. Вивантаження результатів у форматі XLSX:
   - Аркуш 1: «Всі магазини» (Зведений звіт з групуванням по магазинах).
   - Аркуші 2..N: Окремий аркуш для кожного магазину з таблицею працівників, відмітками ✅/❌ та датами.

## 2. Архітектура та компоненти

### 2.1. Шар бази даних (`database/material_notifications.py`)
- `get_all_material_events(days_limit: int = 90) -> List[Dict[str, Any]]`:
  - Отримує список усіх подій `material_change_events` за останні `days_limit` днів, відсортованих за `created_at DESC`.
- `get_event_overall_stats(event_id: int) -> Dict[str, Any]`:
  - Рахує загальну кількість отримувачів, кількість ознайомлених, неознайомлених та відсоток для події (по всіх ролях разом).
- `get_event_shops_summary(event_id: int) -> List[Dict[str, Any]]`:
  - Повертає згрупований список магазинів для події з полями: `shop`, `total_users`, `ack_users`.
- `get_event_all_shop_users(event_id: int, shop: str) -> List[Dict[str, Any]]`:
  - Повертає всіх співробітників зазначеного магазину для події з полями:
    `user_id`, `role_type`, `full_name`, `username`, `status`, `sent_at`, `acknowledged_at`, `is_late`.
  - Сортування: спочатку `'керівник'`, потім `'працівник'`, потім `'стажер'`.

### 2.2. Генератор XLSX (`bot/services/material_ack_excel.py`)
Створює Excel-документ за допомогою бібліотеки `openpyxl`:
- **Аркуш «Всі магазини»**:
  - Метадані події (посада, день, дата, опис).
  - Зведена таблиця:
    - `Магазин`
    - `Категорія`
    - `ПІБ`
    - `Username`
    - `Статус` (`✅ Ознайомлений` / `❌ Не ознайомлений`)
    - `Дата ознайомлення`
    - `Вчасно / Запізнення`
- **Окремий аркуш на кожен магазин**:
  - Назва вкладки відповідає назві магазину (очищена від заборонених символів Excel та скорочена до 31 символу).
  - Локальна таблиця персоналу магазину та підсумковий рядок зі статистикою ознайомлення.
- Стилізація: закріплений заголовок (freeze panes), фірмові кольори, авто-підбір ширини колонок, рамки.

### 2.3. Меню та навігація (`bot/menus/developer.py`)
- `dev_an_ack_menu`: точка входу (перенаправляє на першу сторінку списку подій `dev_ack_events_list:0`).
- `developer_ack_events_list_view` (`dev_ack_events_list:{page}`):
  - Список дат із пагінацією.
  - Кнопка повернення: `⬅️ Назад` (`callback_data="dev_main_analyt"`).
- `developer_ack_event_card_view` (`dev_ack_ev:{event_id}:{page}`):
  - Картка зведеної статистики події.
  - Кнопка `[ 📝 Зміст змін ]` (`dev_ack_changes:{event_id}:{page}`).
  - Кнопка `[ 📥 Вивантажити результати (XLSX) ]` (`dev_ack_export_xlsx:{event_id}`).
  - Інлайн-кнопки магазинів: `🏪 {shop} (✅ {ack}/{total})` (`dev_ack_shop:{event_id}:{shop_enc}:{page}`).
  - Кнопка повернення: `⬅️ Назад` (`dev_ack_events_list:0`).
- `developer_ack_shop_users_view` (`dev_ack_shop:{event_id}:{shop_enc}:{page}`):
  - Деталі магазину з розділенням: 👔 Керівник, 👷 Працівники, 🎓 Стажери.
  - Кнопка повернення: `⬅️ Назад` (`dev_ack_ev:{event_id}:{page}`).
- `developer_ack_changes_view` (`dev_ack_changes:{event_id}:{page}`):
  - Відображає повний текст змін та сторінок матеріалу.
  - Кнопка повернення: `⬅️ Назад` (`dev_ack_ev:{event_id}:{page}`).
- `developer_ack_export_xlsx_callback` (`dev_ack_export_xlsx:{event_id}`):
  - Генерує файл Excel та надсилає його через `bot.send_document`.

## 3. План тестування (Verification)
Скрипт перевірки:
1. Вибірка всіх подій через `get_all_material_events()`.
2. Коректність підрахунку `get_event_overall_stats()` та `get_event_shops_summary()`.
3. Коректність структури `get_event_all_shop_users()` (розподіл ролей, дати, статуси ✅/❌).
4. Генерація Excel-файлу за допомогою `generate_material_ack_xlsx(event_id)`.
5. Валідація згенерованого файлу (перевірка аркуша «Всі магазини» та окремих аркушів для кожного магазину, перевірка значень у комірках).
