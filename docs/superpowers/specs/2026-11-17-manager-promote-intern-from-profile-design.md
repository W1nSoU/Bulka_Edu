# Дизайн специфікація: Кнопка «Перевести на працівника» у профілі стажера для керівника

## 1. Мета та контекст
Забезпечити керівнику магазину зручну можливість перевести стажера в статус повноцінного працівника безпосередньо з картки стажера (меню «🐾 Мої булка-кошенята» / «Список стажерів»), з екраном підтвердження для уникнення випадкових натискань.

## 2. Архітектурні компоненти та зміни

### 2.1. Інтерфейс картки стажера (`bot/handlers.py`)
- У функції `manager_intern_profile_handler`:
  - Отримуємо деталі користувача `user = await get_user_details(intern_id)`.
  - Якщо `user` не має статусу `'Працівник'` (`user.get("status") != "Працівник"`), додаємо кнопку:
    `[🎓 Перевести на працівника]` з callback: `mgr_promote_prompt:{intern_id}:profile`.
  - Якщо користувач уже є працівником, кнопка не показується.

### 2.2. Екран підтвердження та переведення (`bot/menus/manager.py`)
- Хендлер `manager_promote_prompt_handler`:
  - Відображає текст підтвердження з попередженням:
    > 🎓 **Переведення у статус Працівника**
    >
    > Ви дійсно бажаєте перевести стажера **[ПІБ]** у статус **Працівника**?
    >
    > ℹ️ *Всі навчальні дні посади буде автоматично відкрито та зараховано як успішно пройдені. Співробітник отримає святкове повідомлення у боті.*
  - Кнопки:
    - `[✅ Так, перевести]` (`mgr_promote_confirm:{intern_id}:{back_cb}`)
    - `[⬅️ Скасувати]` — якщо `back_cb == "profile"`, повертає до `manager_intern_profile_{intern_id}`.
- Хендлер `manager_promote_confirm_handler`:
  - Викликає `update_user_role(intern_id, "Працівник", actor_id=callback.from_user.id)`.
  - Якщо `back_cb == "profile"`:
    - Відправляє `callback.answer("✅ Стажера успішно переведено у статус «Працівник»!", show_alert=True)`.
    - Оновлює повідомлення на профіль співробітника через `manager_intern_profile_handler` (або `_show_intern_details`).
  - Надсилає вітальне повідомлення стажеру в приватний чат з ботом.

## 3. Обробка помилок та граничні випадки
- Стажера не знайдено: alert `«Стажера не знайдено в системі»`.
- Користувач уже працівник: безпечний alert `«Співробітник уже переведений у статус Працівника»`.
- Некоректні дані callback: безпечний alert `«Помилка ідентифікатора»`.

## 4. Тестування
- Модульний тест перевіряє:
  1. Наявність кнопки у стажера та відсутність у працівника.
  2. Перехід до запиту підтвердження з параметром `profile`.
  3. Скасування дії (повернення до профілю).
  4. Підтвердження переведення (всі дні стають відкритими та завершеними, статус оновлюється, відправляється привітання).
