# Технічне завдання (ТЗ): Створення B2B сайту для TAB Agency

## 1. Загальна інформація
- **Проєкт:** Корпоративний лендінг TAB Agency
- **Цільова аудиторія:** Власники та топ-менеджери офлайн-бізнесів (ритейл, продуктові магазини, автодилери, ТЦ, забудовники).
- **Головний меседж:** "Головна проблема бізнесу сьогодні - це не конкуренти. Це рутина, яка забирає ваш час, і людський фактор, який впливає на ваші гроші. Мене звати Даніїл, і я займаюсь тим, що звільняю власників бізнесу від операційки за допомогою автоматизації та ШІ."

## 2. Дизайн-система (Trust & Authority)
- **Візуальний стиль:** Editorial Authority (строгий, преміальний, асиметричний, з фокусом на експертизу та текст). Без "штучного інтелекту" у вигляді неону чи градієнтів.
- **Шрифт:** IBM Plex Sans (асоціюється з фінансами, консалтингом, надійністю).
- **Палітра кольорів:**
  - Primary (Темно-синій): `#0F172A`
  - Secondary (Сіро-синій): `#334155`
  - Accent / CTA (Стриманий синій): `#0369A1`
  - Background (Світло-сірий): `#F8FAFC`
  - White: `#FFFFFF`
- **UI Елементи:** Мінімалістичні "pill-shaped" кнопки для другорядних дій, строгі прямокутні (з невеликим скругленням) для CTA. Багато білого простору.

## 3. Структура сторінки
1. **Навігація (Header):** Логотип (TAB), Якірні посилання (Експертиза, Кейси, Контакти), Кнопка "Записатись на аудит" (accent).
2. **Головний екран (Hero - Асиметрія):**
   - Ліворуч: Головний меседж, CTA кнопки ("Написати Даніїлу", "Подивитись кейси").
   - Праворуч: Велика цитата клієнта.
3. **Соціальний доказ (Logos):** "Працюємо з офлайн-бізнесом" + логотипи/назви ніш.
4. **Експертиза (Як це працює):**
   - Вертикальний список напрямків замість карток (Telegram-боти, CRM, Софт). Кожен напрямок розписаний "людською" мовою з описом болю та рішення.
5. **Кейси (Portfolio):**
   - Інтеграція скріншотів з реальними цифрами та текстом.
   - Скріншоти інтерфейсів (мобільні екрани ботів, десктопні CRM) вмонтовані в чистий мокап без зайвого шуму.
6. **Заклик до дії (Dark CTA):**
   - Темний блок. Пропозиція безкоштовної 30-хвилинної консультації для розбору процесів.

## 4. Контент та Копірайтинг
- **Humanizer Rules:** Використання активного стану. Жодних тире (em-dashes). Відмова від кліше типу "трансформаційні рішення", "безшовна інтеграція". Текст має звучати як жива розмова з власником бізнесу.
- **SEO стратегія:** 
  - Title: TAB Agency | Автоматизація бізнесу: Telegram-боти та CRM
  - Focus keywords: автоматизація бізнесу, CRM для рітейлу, розробка Telegram-ботів, облік для автосалонів.
  - H1, H2, H3 використовуються семантично та містять болі бізнесу.

## 5. Технічні вимоги (Frontend)
- HTML5 семантика (`<header>`, `<main>`, `<section>`, `<article>`).
- Vanilla CSS для максимального контролю та перфомансу. Жодних фреймворків без потреби.
- Адаптивність (Mobile First підхід для базових стилів, медіазапити для десктопу).
- Доступність (A11y): правильні контрасти, aria-теги для скрінрідерів.
